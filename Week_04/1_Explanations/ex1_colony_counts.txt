WEEK 4 - EXERCISE 1: COLONY COUNTS, LISTED
==========================================
Solution code: 2_Solutions\ex1_colony_counts.py
Try it yourself FIRST. Look at the solution only after you have a go.


WHAT THE QUESTION IS ASKING
---------------------------
You get a list of 5 penguin counts:

    counts = [242, 60, 120, 80, 182]

You must do 5 small jobs with it: read items, add an item, change an
item, do some maths on it, and remove an item.


WHAT YOU NEED TO KNOW
---------------------
A LIST is a row of boxes. Each box has a number called its INDEX.
Python starts counting at 0, not 1.

    value:   242   60   120   80   182
    index:    0     1    2     3    4
    from end: -5   -4   -3    -2   -1

  counts[0]      -> 242   (first item)
  counts[-1]     -> 182   (last item, counted from the end)
  counts[1:4]    -> [60, 120, 80]   a SLICE: from index 1 up to,
                                    but NOT including, index 4

Useful tools:
  counts.append(x)   add x to the END of the list
  counts[i] = x      put x into box i (replaces what was there)
  sum(counts)        add up every number
  max(counts)        the biggest number
  sorted(counts)     a NEW sorted list (the original is not changed)
  counts.count(x)    how many times x appears
  counts.pop()       remove the LAST item and give it back to you


STEP BY STEP
------------
1. First, last, middle three:
       print(counts[0])       -> 242
       print(counts[-1])      -> 182
       print(counts[1:4])     -> [60, 120, 80]
   Why 1:4 and not 1:3? The slice stops BEFORE the second number.
   The middle three are at index 1, 2, 3, so you write 1:4.

2. Append 140:
       counts.append(140)     -> [242, 60, 120, 80, 182, 140]

3. Replace 60 with 74 IN PLACE. 60 is at index 1, so:
       counts[1] = 74         -> [242, 74, 120, 80, 182, 140]
   "In place" means you change the same list. You do NOT write a new
   list by hand.

4. Total, largest, sorted copy:
       sum(counts)     -> 838
       max(counts)     -> 242
       sorted(counts)  -> [74, 80, 120, 140, 182, 242]
   Then print counts again to prove the original order did not change.

5. Count and pop:
       counts.count(242)  -> 1
       removed = counts.pop()   -> removed is 140
   Save what pop() gives back in a variable, so you can print it.


EXPECTED OUTPUT (from the solution file)
----------------------------------------
First: 242
Last: 182
Middle three: [60, 120, 80]
After append: [242, 60, 120, 80, 182, 140]
After fix: [242, 74, 120, 80, 182, 140]
Total: 838
Largest: 242
Sorted copy: [74, 80, 120, 140, 182, 242]
Original still: [242, 74, 120, 80, 182, 140]
242 appears 1 time(s)
Popped off: 140
List now: [242, 74, 120, 80, 182]


COMMON MISTAKES
---------------
* counts[1:3] for the middle three. That gives only 2 items. The end
  number is NOT included.
* counts.sort() instead of sorted(counts). sort() changes the original
  list, and the question says to keep it unsorted.
* print(counts.sort()) prints None, because sort() returns nothing.
* counts[5] on a 5-item list -> IndexError: list index out of range.
  The last index is 4, which is len - 1.
